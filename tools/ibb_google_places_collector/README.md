# Ibb Google Places Grid Audit

المجلد يحتفظ بخطة شبكة 300×300 متر متوافقة مع احتياجات المشروع، لكن **لا يُستخدم لكشط Google Maps أو لتصدير قاعدة بيانات من Google Places**.

شروط Google الحالية تمنع استخراج/كشط محتوى Google Maps واستخدامه خارج الخدمة في حالات محددة، كما تتضمن قيودًا على تنزيل معلومات الأماكن بالجملة وعلى استخدام Places Content مع خريطة غير Google. لذلك لا نستخدم Playwright أو Selenium لمحاكاة خرائط Google، ولا نُنتج ibb_shops.csv من Google.

للتغطية القابلة للتخزين في مشروع محرك السوق اليمني، المسح الشبكي الجاري يعتمد على OpenStreetMap/Overpass ومصادر مرخصة أو بيانات يقدّمها التجار مباشرة.

نطاق شبكة إب الحالية:
13.9300 <= latitude <= 14.0300
44.1300 <= longitude <= 44.2200
step = 300 متر تقريبًا

ملف ibb_city_box.json يصف النطاق فقط.
