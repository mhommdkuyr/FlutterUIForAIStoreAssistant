# بحث السوق التجاري في إب — 2026-10-03

هذه الحزمة بحث استكشافي لمشروع «محرك السوق اليمني».

## ملاحظات مهمة
- استخدمت Google Maps/Business Search للاستكشاف وتحديد الممرات والعقد التجارية، ولم أقم بتصدير أو نسخ قاعدة بيانات Google Maps إلى هذا المستودع.
- بيانات OSM/المصادر المفتوحة موثقة بروابط المصدر وملاحظات الترخيص.
- الصور التجارية الخارجية لم تُرفع إلى المستودع عندما كان ترخيص إعادة الرفع غير واضح؛ أُدرجت روابطها وحالة الترخيص فقط.
- صور المتاجر والمنتجات للمشروع النهائي ينبغي أن يرفعها صاحب النشاط أو تكون مرخصة صراحة لإعادة الاستخدام.

## الملفات
- report.md — التقرير التنفيذي.
- data/ibb_commercial_zones.csv — الممرات والعقد التجارية المرشحة.
- data/ibb_markets_osm.csv — نقاط أسواق مفتوحة مع الإحداثيات والمصادر.
- data/ibb_population_baseline.csv — خط أساس ديموغرافي تاريخي للاستخدام التخطيطي.
- data/image_sources.csv — صور حقيقية مرتبطة بإب/اليمن وحالة إعادة الاستخدام.
- NOTICE.md — ملاحظات الحقوق والتراخيص.

## حالة البحث
الاستكشاف يبين نشاطًا متعدد القطاعات حول شارع العدين، شارع تعز، شارع المحافظة/القلب المركزي، سوق الظهار والسوق المركزي، خط الجامعة، الدائري الغربي/مفرق جبلة، مثلث المنصوب، ميتم، وشارع الخنساء. هذه خريطة أولية وليست تعدادًا إحصائيًا للمنشآت.
