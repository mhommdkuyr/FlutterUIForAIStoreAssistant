# AI Store Assistant — Flutter Mobile Application

> An AI-powered retail management platform for grocery stores and small businesses in Yemen and beyond.

---

## Training pipeline

The staged Yemen-market visual catalog pipeline is active on PR #24. It builds six 500-SKU batches, validates MobileCLIP2 512D embeddings, assembles the 3000-SKU catalog, runs the Flutter recognition tests, and only then builds the release APK.

## Overview

AI Store Assistant is a production-ready Flutter application foundation for inventory, checkout, analytics, role-based access, branch management, marketing, debt tracking, and visual product recognition.
